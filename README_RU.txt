GRIM_GG — первая версия сайта Mobile Legends

СОСТАВ
- index.html — разметка сайта
- styles.css — чёрно-красный неоновый дизайн и мобильная адаптация
- script.js — интерактивные фильтры героев, подбор контрпика, карточки сборок и раскрывающиеся гайды

КАК ПРОВЕРИТЬ
1. Распакуйте архив в папку.
2. Откройте index.html в современном браузере на телефоне или компьютере.
3. Для публикации загрузите все три файла в одну папку репозитория/сайта.

БЕСПЛАТНАЯ ПУБЛИКАЦИЯ ЧЕРЕЗ GITHUB PAGES
1. Создайте аккаунт на https://github.com/ (если его ещё нет).
2. Создайте новый публичный репозиторий, например grim-gg.
3. Нажмите Add file → Upload files и загрузите index.html, styles.css, script.js.
4. Нажмите Commit changes.
5. Откройте Settings → Pages.
6. В разделе Build and deployment выберите Deploy from a branch.
7. Выберите ветку main и папку /(root), затем Save.
8. Дождитесь публикации. В разделе Pages появится ссылка вида https://ВАШ-ЛОГИН.github.io/grim-gg/.

Если ссылка не появилась сразу, подождите несколько минут и обновите страницу Pages.

ВАЖНО
- Это статический сайт: сервер и платная база данных не нужны.
- Данные о героях, контрпиках и сборках демонстрационные и требуют проверки/обновления под актуальный патч.
- Логотипы и официальные изображения героев намеренно не включены; используйте только материалы, на которые у вас есть права.
- Это фанатский проект, не связанный официально с Moonton/Mobile Legends.
- Публикация сайта не приносит деньги автоматически. Доход зависит от аудитории, контента и одобрения рекламных/партнёрских программ.
